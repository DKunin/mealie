# Журнал изменений

## Не выпущено

- Добавлено развёртывание Mealie для `meal.kunini.ru`: закреплённый образ,
  локальный порт, русский язык по умолчанию, TLS, безопасная инициализация
  администратора и проверки рабочего сервиса.
- Штатная авторизация заменена на OIDC через `auth.kunini.ru`; password login и
  OIDC-регистрация отключены, client secret подключается как Docker secret,
  публичный endpoint выдачи password token закрыт в Nginx.
- Добавлен идемпотентный импорт 501 русскоязычного рецепта UniTools 2.0.0 с
  проверкой SHA-256, атрибуцией CC BY-SA 4.0, нормализованными продуктами,
  единицами, категориями, тегами, шагами и КБЖУ.

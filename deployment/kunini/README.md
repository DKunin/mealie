# Mealie на `meal.kunini.ru`

Развёртывание использует официальный Mealie `v3.30.0`, закреплённый по digest,
SQLite и Nginx. Контейнер доступен только на `127.0.0.1:9001`, самостоятельная
регистрация отключена, данные хранятся вне Git в `/var/apps/mealie/data`.

Русский язык включается для первого посещения через cookie `ru-RU`. После этого
пользователь может выбрать другой язык в интерфейсе. Часовой пояс —
`Europe/Moscow`, начальные названия группы и семьи — «Дом» и «Семья».

## Первое развёртывание

```bash
cd /var/apps/mealie/deployment/kunini
./deploy.sh
./bootstrap-admin.sh
./setup-nginx.sh
```

Администратор: `dkunin` (`dkunin@kunini.ru`). Случайный пароль хранится только на
сервере в `/var/apps/mealie/secrets/admin-password` с правами `0600`. Не добавляйте
его в Git и не передавайте в аргументах командной строки.

## Проверка

```bash
cd /var/apps/mealie/deployment/kunini
./verify.sh
```

Проверяются версия, точный образ, состояние контейнера, локальный порт,
постоянный том, TLS, обязательная авторизация и русский язык по умолчанию.

## Обновление и откат

Перед обновлением создайте архив в «Панель администратора → Резервные копии» и
скопируйте его с сервера. Затем прочитайте примечания к выпуску, обновите tag и
digest в `compose.yaml` и `.env.example`, выполните `deploy.sh` и `verify.sh`.

Для отката верните предыдущую версию файлов развёртывания и образа. Если новая
версия успела изменить схему данных, восстановите созданный перед обновлением
архив через интерфейс Mealie; запуск старого образа на новой базе небезопасен.

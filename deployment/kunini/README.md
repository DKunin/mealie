# Mealie на `meal.kunini.ru`

Развёртывание использует официальный Mealie `v3.30.0`, закреплённый по digest,
SQLite и Nginx. Контейнер доступен только на `127.0.0.1:9001`, самостоятельная
регистрация и вход по паролю отключены, данные хранятся вне Git в
`/var/apps/mealie/data`. Вход выполняется через Kunini Auth по OIDC
authorization-code flow с PKCE; callback — `https://meal.kunini.ru/login`.

Русский язык включается для первого посещения через cookie `ru-RU`. После этого
пользователь может выбрать другой язык в интерфейсе. Часовой пояс —
`Europe/Moscow`, начальные названия группы и семьи — «Дом» и «Семья».
Публичный `/api/auth/token` закрыт в Nginx, поскольку настройка Mealie
`ALLOW_PASSWORD_LOGIN=false` скрывает форму, но сама по себе не отключает endpoint.
Loopback upstream остаётся доступен на сервере для аварийного отката.

## Первое развёртывание

До запуска зарегистрируйте клиент `mealie` в Kunini Auth и положите тот же secret
в `/var/apps/mealie/secrets/oidc-client-secret` с правами `0600`. Secret не
передаётся через environment и монтируется в контейнер как Docker secret.

```bash
cd /var/apps/mealie/deployment/kunini
./deploy.sh
./bootstrap-admin.sh
./setup-nginx.sh
```

Администратор: `dkunin` (`dkunin@kunini.ru`). Случайный пароль хранится только на
сервере в `/var/apps/mealie/secrets/admin-password` с правами `0600`. Не добавляйте
его в Git и не передавайте в аргументах командной строки. После проверки OIDC он
остаётся только для аварийного отката конфигурации; штатный вход по паролю закрыт.

## Каталог рецептов

Импортёр `import_unitools_recipes.py` загружает 501 рецепт на русском языке из
UniTools World Recipes 2.0.0. Набор закреплён за commit
`2f554073f7e730b18d707fe1164d18308f6ec16c` и SHA-256
`41fdc0572b7272ca557d2df22a0fac1cc1f18146e97ebd2c8258c395daf87d8a`.
Лицензия данных — CC BY-SA 4.0; атрибуция и сведения о лицензии сохраняются в
описании, заметке и дополнительных полях каждого рецепта.

Импорт создаёт отдельные сущности Mealie: 12 единиц измерения, 672
нормализованных продукта, категории блюда и кухни, теги диет и сложности,
структурированные ингредиенты, шаги и КБЖУ. Варианты названий и нелинейное
масштабирование сохраняются в примечании ингредиента. Повторный запуск пропускает
уже загруженные рецепты и останавливается при конфликте с пользовательским
рецептом с тем же названием.

```bash
./import_unitools_recipes.py \
  --dataset /path/to/unitools-recipes-v1.json \
  --token-file /path/to/temporary-mealie-token
```

Файл токена должен быть временным, с правами `0600`; удалите его сразу после
импорта. Фотографии не загружаются, чтобы не расходовать место: исходный URL,
автор и лицензия фотографии остаются в дополнительных полях рецепта.

## Проверка

```bash
cd /var/apps/mealie/deployment/kunini
./verify.sh
```

Проверяются версия, точный образ, состояние контейнера, локальный порт,
постоянный том, TLS, OIDC-only вход через Kunini Auth и русский язык по умолчанию.

## Обновление и откат

Перед обновлением создайте архив в «Панель администратора → Резервные копии» и
скопируйте его с сервера. Затем прочитайте примечания к выпуску, обновите tag и
digest в `compose.yaml` и `.env.example`, выполните `deploy.sh` и `verify.sh`.

Для отката верните предыдущую версию файлов развёртывания и образа. Если новая
версия успела изменить схему данных, восстановите созданный перед обновлением
архив через интерфейс Mealie; запуск старого образа на новой базе небезопасен.
